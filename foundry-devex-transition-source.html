11 · VS Code UI system

Why the UI system started.

2024

The official toolkit was deprecated

VS Code extensions no longer had an official UI component system.

The problem

Two teams were solving the same problem separately

Because Fluent did not look like VS Code, each extension team built its own CSS overrides. Once packaged together, those separate approaches made the combined extension feel even less consistent.

Amy stepped up

Designing and coding a shared layer

Amy decided to design and code a component layer that makes Fluent feel native to VS Code, collaborating with Hui as the engineering reviewer.

Today

Basic components are published

New extension features already use these components, and we have started replacing them in some older features.

The remaining legacy cleanup and system iteration will continue as resources allow.
